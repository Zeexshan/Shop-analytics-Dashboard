# 🏪 Complete Shop Analytics Dashboard - Ultra-Detailed Development Blueprint

You are an expert full-stack developer tasked with creating a **professional-grade Shop Analytics Desktop Application** from scratch. This will be a standalone Windows desktop application with a complete backend, modern React frontend, and comprehensive business intelligence features for a shop owner.

## 🎯 **PROJECT OVERVIEW**
Build a complete desktop application that allows a shop owner to:
- Track sales, expenses, and inventory in real-time
- View comprehensive analytics with beautiful charts and KPIs
- Manage products with full CRUD operations and stock tracking
- Set and monitor monthly/yearly revenue goals
- Export data and generate reports
- Access everything through a secure, user-friendly interface

## 🗄️ **PHASE 2: DATABASE & EXCEL INTEGRATION**

### **2.1 Excel Database Schema**
Create a comprehensive Excel seeder (`scripts/seed.cjs`) that generates `data/shop_data.xlsx` with these exact sheets:

**Products Sheet Headers:**
- `id` (unique identifier)
- `name` (product name)
- `description` (product description)
- `price` (selling price in rupees)
- `cost_price` (purchase/manufacturing cost)
- `category` (product category)
- `stock` (current stock quantity)
- `min_stock` (minimum stock threshold for alerts)
- `supplier` (supplier name)
- `sku` (stock keeping unit)
- `created_date` (when product was added)
- `last_updated` (last modification date)

**Sales Sheet Headers:**
- `id` (unique sale ID)
- `product_id` (reference to product)
- `product_name` (product name for easier reading)
- `quantity` (quantity sold)
- `unit_price` (price per unit at time of sale)
- `total_amount` (quantity × unit_price)
- `profit` (total_amount - (cost_price × quantity))
- `customer_name` (optional customer name)
- `payment_method` (Cash/Card/UPI/Online)
- `sale_date` (date and time of sale)
- `cashier` (who made the sale)
- `notes` (optional notes)

**Expenses Sheet Headers:**
- `id` (unique expense ID)
- `category` (Rent/Utilities/Inventory/Marketing/Staff/Other)
- `description` (expense description)
- `amount` (expense amount in rupees)
- `payment_method` (Cash/Card/Bank Transfer)
- `vendor` (who was paid)
- `expense_date` (date of expense)
- `receipt_number` (optional receipt reference)
- `notes` (additional notes)

**Goals Sheet Headers:**
- `id` (unique goal ID)
- `period_type` (Monthly/Quarterly/Yearly)
- `target_period` (e.g., "2024-01" for January 2024)
- `revenue_goal` (target revenue amount)
- `profit_goal` (target profit amount)
- `sales_goal` (target number of sales)
- `created_date` (when goal was set)
- `status` (Active/Completed/Cancelled)

### **2.2 Advanced Storage Module Requirements**
The `backend/storage.cjs` must implement these functions with full error handling:

**Product Management:**
- `getAllProducts()` - Return all products with calculated low stock alerts
- `getProductById(id)` - Get single product details
- `addProduct(productData)` - Add new product with validation
- `updateProduct(id, updates)` - Update product (including stock adjustments)
- `deleteProduct(id)` - Delete product (check for existing sales first)
- `getLowStockProducts(threshold)` - Get products below minimum stock
- `updateProductStock(productId, newStock)` - Direct stock update
- `getProductsByCategory()` - Group products by category

**Sales Management:**
- `getAllSales()` - Get all sales with product details
- `getSaleById(id)` - Get single sale details
- `addSale(saleData)` - Add sale AND automatically reduce product stock
- `updateSale(id, updates)` - Update sale (handle stock adjustments)
- `deleteSale(id)` - Delete sale (restore stock quantity)
- `getSalesByDateRange(startDate, endDate)` - Filter sales by date
- `getSalesByProduct(productId)` - Get sales history for a product
- `getDailySales()` - Group sales by day for charts

**Expense Management:**
- `getAllExpenses()` - Get all expenses
- `getExpenseById(id)` - Get single expense
- `addExpense(expenseData)` - Add new expense
- `updateExpense(id, updates)` - Update expense
- `deleteExpense(id)` - Delete expense
- `getExpensesByCategory()` - Group expenses by category
- `getExpensesByDateRange(startDate, endDate)` - Filter expenses

**Goal Management:**
- `getAllGoals()` - Get all goals
- `getActiveGoals()` - Get currently active goals
- `addGoal(goalData)` - Create new goal
- `updateGoal(id, updates)` - Update existing goal
- `deleteGoal(id)` - Delete goal
- `getGoalProgress(goalId)` - Calculate current progress vs target

**Analytics Functions:**
- `getRevenueAnalytics(dateRange)` - Revenue calculations with trends
- `getProfitAnalytics(dateRange)` - Profit calculations and margins
- `getTopSellingProducts(limit, dateRange)` - Best performing products
- `getCategoryPerformance(dateRange)` - Performance by product category
- `getMonthlyTrends()` - Month-over-month growth calculations
- `getDashboardKPIs(dateRange)` - All key performance indicators

### **10.2 Critical Business Logic**
**Stock Management Rules:**
- When a sale is made, automatically reduce product stock
- Prevent overselling (validate stock availability)
- Generate low stock alerts based on minimum thresholds
- Track stock movements (sales, adjustments, returns)
- Calculate stock valuation for financial reports

**Financial Calculations:**
- Revenue = Sum of all sales
- Profit = Revenue - (Cost of Goods Sold + Expenses)
- Profit Margin = (Profit / Revenue) × 100
- ROI = (Profit / Total Investment) × 100
- Break-even point calculations
